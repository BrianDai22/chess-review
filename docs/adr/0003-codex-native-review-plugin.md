# Codex-native review plugin

Package the personal chess review tool as a local Codex plugin with an embedded MCP App, semantic chess tools, and coaching instructions, so the board and native subscription conversation share one workspace. The local backend remains the authority for games, review sessions, engine analysis, and one scoring method; the app supplies manual position changes through model-context updates and uses live reads and revision checks for tool actions. This replaces the separate browser interface and chat handoff; embedded UI support in Brian's installed host must be proven before the full build, the scoring formula remains unresolved, and this decision does not authorize application implementation or configuration changes.
