# Independent documented scoring

Brian accepts one independent documented scoring method whose numbers can differ from Chess.com's CAPS2 results. Every game, classification, progress comparison, and coaching tool must use the same canonical local results; optional imported accuracy and language-model-assigned scores remain excluded. A pinned public accuracy method is the recommended foundation, but its precise calibration, special-label predicates, and retry tolerance still require specification and validation before implementation.
